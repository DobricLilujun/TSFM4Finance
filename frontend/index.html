About

About This System

Unified interface
All models and data are unified into a “timestamp × feature” matrix, with explicit context window and horizon. See docs/02_unified_interface_spec.md.
Open / closed dual track
Open data is evaluated publicly into the leaderboard; closed data requires a model upload (private mode) or data provisioning.
Multi-domain, multi-task
Stocks / indices / FX / crypto / bonds / commodities — tasks include forecast / classification / anomaly detection.
Configurable
The supported dataset list is managed in the encrypted admin backend — toggle datasets on or off and the site updates automatically.
