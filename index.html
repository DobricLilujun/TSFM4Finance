One fair stage for financial time-series models

Finance TSFMs Arena is an open, reproducible benchmark and leaderboard for financial time-series forecasting. It unifies models and data into a single “timestamp × feature” interface, supports open + closed tracks across stocks, indices, FX, crypto, bonds and commodities, and ranks them on one composite score — computed locally on real data.

Unified interface
Every model and dataset is cast into one “timestamp × feature” matrix with explicit context window and horizon — so a fair comparison is possible across models that were never designed to be compared.
Open + closed tracks
Open data is evaluated publicly into the leaderboard; closed / proprietary data runs in private mode (local only) so nothing unpublished is exposed.
Real, reproducible data
Scores are computed from real market data, not fabricated — and published-benchmark results are kept separate from the live arena and cited to their source papers.

About

About This System

Unified interface
All models and data are unified into a “timestamp × feature” matrix, with explicit context window and horizon. See docs/02_unified_interface_spec.md.
Open / closed dual track
Open data is evaluated publicly into the leaderboard; closed data requires a model upload (private mode) or data provisioning.
Multi-domain, multi-task
Stocks / indices / FX / crypto / bonds / commodities — tasks include forecast / classification / anomaly detection.
Configurable
The supported dataset list is managed in the encrypted admin backend — toggle datasets on or off and the site updates automatically.
